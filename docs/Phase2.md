# Phase Two
This document defines the features scoped for after the initial release of the new site.
For general requirements/documentation, see `docs/REQUIREMENTS.md`.

## Key Features
1. **Improved authentication** using either email/password or magic link
2. **File upload** for board members only (requires basic permissions structure)
3. **Trust contractors** list for reference organized by type of work they do
4. **Community board** to post announcements - opt into email notification
5. **FAQ** for common resident question (e.g. butterfly door app, security camera, how to pay dues)
6. **Roles/Permissions** to give board members permissions: e.g. document:upload, document:delete, resident:create, resident:delete, resident:update
7. **User Management** screen to give authorized users a way to add new residents
8. **Invite only** membership: users have to be added by an admin: no signup form
